# MonProfe - AI Study Assistant

MonProfe is an AI-powered study assistant that helps students learn smarter from their own notes. Students can upload PDFs/notes and instantly get summaries, explanations, quizzes, flashcards, expected exam questions, and chat with their documents.

### 🚀 Key Features
- **Smart Upload:** Upload PDFs, notes, and study materials
- **AI Summarization:** Get concise summaries and simple explanations of complex topics
- **Active Learning:** Auto-generates quizzes, flashcards, and expected questions from your notes
- **Chat with Notes (RAG):** Ask any question from your uploaded documents and get AI-based answers
- **Secure & Personal:** User authentication with JWT, personal dashboard to track all study materials

### 🛠️ Tech Stack
- **Backend:** Python, FastAPI
- **Frontend:** React, Vite, Tailwind CSS
- **Database:** SQLite with SQLAlchemy ORM
- **AI & Search:** Google Gemini API, LangChain, FAISS Vector DB
- **Auth:** JWT Authentication
